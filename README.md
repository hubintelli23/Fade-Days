# Fade & Days — Web Starter

이 프로젝트는 Fade & Days의 첫 번째 UI 프로토타입입니다.

## 실행
1. `index.html` 파일을 브라우저에서 엽니다.
2. 하단 메뉴로 홈 / 타임라인 / 앨범 / 마이 화면을 이동합니다.
3. 타임라인에서 `+ 기록 추가`를 눌러 샘플 기록을 추가할 수 있습니다.

## 현재 구현 범위
- 반응형 화면 레이아웃
- 하단 탭 이동
- 기록 추가 폼과 화면 내 목록 반영
- 샘플 콘텐츠

## 아직 구현되지 않은 기능
- 사진 파일 업로드 및 영구 저장
- 로그인 / 계정
- 서버 동기화 및 파트너 공유
- 실제 앨범 생성 및 편집
- PWA 오프라인 캐시
- Capacitor / Android APK 패키징

현재는 브라우저에서 실행하는 UI 프로토타입입니다. 실제 데이터 저장과 사진 공유는 다음 개발 단계에서 구현합니다.
