# Fade & Days 웹앱 (v0.3.0) — Node.js 없이 바로 쓰는 배포본

이 폴더는 이미 빌드된 완성본입니다. 설치할 프로그램이 없습니다.
폴더 안의 파일을 그대로 웹에 올리기만 하면 휴대폰과 PC에서 열 수 있습니다.

## 1. GitHub Pages에 올리기 (5분)

1. GitHub에서 새 저장소를 만듭니다. (예: `fade-and-days`, Public)
2. 저장소 화면 → **Add file → Upload files** → 이 폴더 안의 파일과 폴더를 **전부** 끌어다 놓고 Commit
   (`index.html`이 저장소 맨 위에 있어야 합니다. `.nojekyll` 파일도 같이 올려 주세요)
3. **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / `/ (root)` → Save
4. 1~2분 뒤 `https://아이디.github.io/fade-and-days/` 에서 열립니다.
5. 휴대폰에서 이 주소를 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.
   (Android Chrome: 마이 → 앱 설정 → 홈 화면에 앱 추가 / iPhone Safari: 공유 → 홈 화면에 추가)

이 상태는 **로컬 모드**입니다. 로그인 없이 각자의 휴대폰 브라우저 안에만 저장되고, 서버로 아무것도 보내지 않습니다.

## 2. 로그인 · 동기화 · 공유 앨범 켜기 (Firebase)

1. https://console.firebase.google.com 에서 프로젝트를 만듭니다.
2. 프로젝트 설정 → 일반 → 내 앱 → 웹(`</>`) 앱 등록 → 나오는 `firebaseConfig` 값을 복사
3. Authentication → 로그인 방법 → **이메일/비밀번호**, **Google** 사용 설정
4. Authentication → 설정 → **승인된 도메인**에 `아이디.github.io` 추가
5. Firestore Database → 데이터베이스 만들기 → 위치 `asia-northeast3 (서울)` → 프로덕션 모드
6. Firestore → **규칙** 탭에 이 폴더의 `firestore.rules` 파일 내용을 붙여 넣고 **게시** (v0.3.0에서 규칙이 바뀌었으니 예전에 게시했다면 다시 게시)
7. GitHub 저장소에서 `config.js`를 열고 연필(✏️) 버튼으로 2번의 값을 채운 뒤 Commit
8. 1~2분 뒤 사이트를 새로고침하면 로그인 화면이 나타납니다.

`config.js`의 값은 비밀번호가 아니라 "어느 Firebase 프로젝트인지" 알려 주는 공개 값이라 GitHub에 올려도 괜찮습니다.
누가 무엇을 볼 수 있는지는 6번의 보안 규칙이 정합니다. **규칙을 꼭 게시하세요.**

- 초대 코드와 링크에는 IP 주소나 와이파이 정보가 들어가지 않습니다.
  링크는 `https://아이디.github.io/fade-and-days/?invite=ABCD2345` 처럼 사이트 주소 + 8자리 코드뿐입니다.
- 코드를 받은 사람은 **로그인한 뒤** 코드를 입력해야 참여할 수 있고, 기간·횟수 제한과 취소가 가능합니다.
- 같은 공유 앨범의 멤버끼리는 서로의 추억과 시간 로그를 **같이 봅니다.** 참여할 때 이 내용이 안내됩니다.
- 보이고 싶지 않은 기록은 작성·수정 화면에서 **‘나만 보기’**로 두면 다른 멤버에게 보이지 않습니다.
- 앨범을 나가거나 내보내지면 그 사람의 기록은 더 이상 다른 멤버에게 보이지 않습니다.
